# Approach fidelity rubric — when the user names an approach

When a note names an approach (cbt, sfbt, act, dbt, mi, smcm, …): **name what was done accurately** without inventing techniques.

## Pass / fail checks

| # | Check | Fail example |
|---|-------|--------------|
| 1 | Technique named only if draft actions match | Draft “talked about worry” → “cognitive restructuring” |
| 2 | Clt response / homework only if stated | Inventing “Clt completed thought record” |
| 3 | Modality style does not erase required note structure | SFBT-washing a risk interview into miracle-only |
| 4 | Scores / scales only if in draft | Inventing SUDS or sleep efficiency |
| 5 | Cross-modality mix only if draft shows it | Adding DBT TIPP when draft only says breathing |
| 6 | Assessment synthesises; does not dump textbook theory | Paragraphs of CBT theory with no session link |
| 7 | No bare modality claim | “CBT done” / “provided CBT” without naming the tool |
| 8 | Keep Clt wording for thoughts/quotes | Overwriting automatic thoughts with textbook jargon |

## Quick fidelity by approach

| approach | Must see in draft before naming | Prefer note phrasing | Fail if you… |
|----------|----------------------------------|----------------------|-------------|
| sfbt | Preferred future / miracle, exception, scaling, or tiny next step | Scale number + meaning; exception behaviour; next step owned by Clt | Invent miracle/exception content |
| cbt | Thought–feeling–behaviour work, exposure steps, BA, experiment, or named worksheet | Name the specific tool used; keep Clt thought wording | Write “CBT done”; invent SUDS/hierarchies/distortion labels/worksheet completion; upgrade “talked about worry” |
| cbti | Sleep diary, restriction/scheduling, stimulus control as done | No invented sleep efficiency % | Invent SE% or adherence % |
| act | Values, defusion, acceptance, committed action as done | Values → one action | Invent metaphors Clt never used |
| dbt | Named skill module or clear skill behaviour | Do not upgrade “breathing” to TIPP unless said | Upgrade vague coping to named DBT skill |
| mi | Ambivalence, OARS moves, decisional balance | Reflect Clt’s own change talk | Write “Clt resistant”; invent readiness stage |
| smcm | Strengths, goals, natural supports, outreach | SMCM vocabulary from smcm | Invent strengths/goals not in draft |
| narrative | Externalising / unique outcomes as done | Keep Clt metaphors | Invent unique outcomes |
| `trauma_informed` | Safety, choice, collaboration language as done | No invented trauma processing labels | Equate TIP with PE/CPT/EMDR |

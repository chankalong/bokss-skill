# Approach knowledge — how a worker uses it

The worker already chose (or was assigned) a way of working: CBT, ACT, DBT, MI, SFBT, SMCM, CBT-I, narrative, trauma-informed… That knowledge is **how I work**, not a session that already happened.

Fidelity checks: [approach-fidelity.md](approach-fidelity.md). Naming detail: [therapy-techniques.md](therapy-techniques.md).

## What sits in the head

| Piece of knowledge | How I use it in the case | How I do not use it |
|--------------------|--------------------------|---------------------|
| What this approach is | Keep labels in-family (CBT ≠ ACT) | Paste a modality definition into Assessment |
| How a session often looks | Check whether *today* had a method | Copy agenda / homework / summary from the recipe |
| Named methods (thought record, defusion, scaling, OARS, graded activity…) | Name the move I **made** | Upgrade “talked about worry” or “did breathing” |
| Formulation ideas (TFB, values, exceptions, 5P mapping) | Sense-making if we actually used them | Fill empty Ps, values, or miracle content |
| Common pairings (CBT with depression, etc.) | Context for choosing work | Pick an intervention only because the pairing is famous |

## Match rule

Contact action → technique name is allowed.  
Technique name → invented contact action is forbidden.

| Today (OK to name) | Today (do not name) |
|--------------------|---------------------|
| Looked at “I’ll faint” for/against | “Talked about worry on the train” → cognitive restructuring |
| Practised one MTR stop further; anxiety rose then settled | “Discussed going out more” → exposure hierarchy |
| Scale 4; what would 5 look like; Clt named a walk | Approach is SFBT but no scale/exception/miracle → miracle question |
| Family matters; agreed one phone call despite dread | Approach is ACT → invented metaphor Clt never used |
| Cooked one dish with prompting; sequenced steps | Approach is CBT → “behavioural experiment” unless that was the frame used |

## Bare modality claims

A worker who “uses CBT” still writes the **element**: testing thoughts, BA, graded exposure, problem-solving. “CBT done” / “provided psychoeducation” is not a case recording.

If the approach is known but today was only conversation, say so. Do not invent a technique to honour the label.

## Approach must not erase the case

| The contact included… | A worker still… |
|-----------------------|-----------------|
| Risk / SI | Records it. SFBT does not wash it into miracle-only |
| OT occupation / home environment | Keeps occupation. CBT does not turn it into a therapy process note |
| SW housing, money, liaison | Keeps the whole case. ACT does not reduce it to hexaflex |
| Cross-method mix | Names only what was done (breathing stays breathing unless TIPP was used) |

## Approach unknown

If a named method is clearly in the contact, you may label it. Do not infer a whole modality or add homework from knowledge.

# Diagnosis knowledge — how a worker uses it

A competent worker does not re-diagnose each session. They **already know** the file frame (Depression, Psychosis, GAD, Suspected - Mood, N/A…). Diagnosis material — manuals, teaching cards, retrieved notes — is the **mental map** behind noticing. It is not today’s assessment.

## What sits in the head

| Piece of knowledge | How I use it in the case | How I do not use it |
|--------------------|--------------------------|---------------------|
| What this condition is | Recognise domains in the person’s story | Paste a definition into Assessment |
| Gate features | “Did any of these show up *today*?” | Fill missing gates so it looks like a full episode |
| Domain / criterion vocabulary | Precise names for what *was* there (Clt words first) | Count items to match the manual |
| Differentials / lookalikes | Stay careful if the story hints (elevated mood, substances, grief, trauma, voices) | Invent a workup I did not do |
| Specifiers (severity, mixed, remission…) | Repeat only if the file already uses them | Pick one to look complete |
| Care often used with this presentation | Options I might choose **in session** | Auto-write them into Plan |
| Official DSM / ICD wording | Match the letter/file if I am citing a label | Assign a new code |

Functional anchors beat abstract criteria when both exist: attendance, self-care, sleep, withdrawal, occupation, relationships.

## File label vs today’s presentation

- **File / intake label** — stay consistent; do not upgrade (Psychosis ↛ schizophrenia; Suspected - Mood ↛ MDD).
- **Today’s presentation** — only domains from this contact. You may describe them *under* the file frame without issuing a new diagnosis.
- If the clinic letter uses different wording (e.g. ICD title vs intake option), keep the **source wording**.

## Administrative and provisional frames

These are how the file is organised, not DSM diagnoses. Work the case anyway.

| Frame | How a worker thinks | How a worker does not think |
|-------|---------------------|-----------------------------|
| **N/A** | Needs and risk in plain language | “Must be depression or psychosis to be a real case” |
| **Others (specify)** | The specified label from file/referral | Leave “Others” blank, or force-fit a listed option |
| **Rejected to Disclose** | Clt declined to share Dx; work presenting concerns | Infer a diagnosis against their wish |
| **Suspected - Mood / Psy** | Mood- or psychosis-spectrum *possible*; specific option not confirmed | Treat as confirmed Depression / schizophrenia |

## Thin contact, known diagnosis

Knowing the frame does not let you borrow the textbook example. Write what happened. If today’s note is thin, it stays thin — and you may flag what you still need to understand (domains not elicited, risk not asked). You do not complete the picture from knowledge.

## Depression extra care

When the frame is depression, keep bipolar / grief / medical / substance distinctions if they appeared; do not pad Criterion A; do not equate a few days of “seemed down” with a major episode.

# Three brains — SW, OT, CP

Same diagnosis and same approach still produce **different cases**. Pick the role first, then notice / work / make sense / write.

## Social worker / Case Worker

Holds the **overall case**: engagement, psychosocial picture, counselling within scope, care coordination, liaison.

### When I know the diagnosis
I do not become the psychiatrist. I use the frame to hear **what this presentation is doing to this person’s life**.

| I hold in mind | I listen for today | I still hold the rest of the case |
|----------------|--------------------|-----------------------------------|
| Gate features and domains of this frame (mood and interest in depression; worry spread in GAD; voices/ideas/negative symptoms in psychosis…) | Change in condition, function (work, self-care, sleep, withdrawal), meds as reported, risk as disclosed | Family, housing, money, job, network, missed appointments, other services |
| Lookalikes (bipolar flags, grief, substance, trauma) | Only if the story hints — I do not run a full differential I did not do | — |

**Suspected / N/A / Rejected to Disclose:** I work the presenting needs and risk. I do not “fill” a diagnosis to make the file tidy.

### When I know the approach
That is *how I counselled or structured this session* — SMCM strengths, CBT thought/behaviour work, MI on ambivalence, SFBT next small step, etc.

- Objective: one clear aim (review X, practise Y, support after Z, liaise with…) — not “support Clt”
- I name the skill I used and the Clt’s response (accepted / hesitation / rejected + why)
- I do not drop housing, family, or liaison because a therapy card is in my head

### How I make sense
- Did I achieve today’s objective? Why / why not?  
- Progress vs care-plan: improving / stuck / fluctuating  
- A pattern or barrier only if today’s contact showed it (avoidance, conflict loop, no-show)  
- Optional 5P if asked and supported — empty Ps stay empty  

### How I write
Objectives → Summary of Content (condition, topic, intervention, response) → Worker’s Assessment → Plan or Action.  
Assessment is not a second Summary. Plan is attributable next steps (I will / Clt will / liaison), not a list of treatments the diagnosis card “often uses”.

## Occupational therapist

Addresses **occupation** through person–environment–occupation. Diagnosis and approach are useful only insofar as they change **doing**.

### When I know the diagnosis
I translate the frame into performance, not into a mini psychiatric formulation.

| Frame (examples) | OT questions I actually use |
|------------------|-----------------------------|
| Depression | Self-care dropped? Sleep participation? Getting out to shop/work? Energy for sequenced tasks? |
| Psychosis | Medication routine, meal prep safety, community mobility, responding to voices while doing a task, home safety |
| GAD / OCD | Avoidance of places/tasks, checking that makes them late, tension that breaks a routine |
| Neurodevelopmental | Sequencing, sensory load in the environment, routine structure |

I document contributing factors I can address (process skills, routines, environment). I do not invent FIM/assist levels, ROM, or COPM scores.

### When I know the approach
I apply it **inside activity**: graded task, behavioural activation as a real occupation, stimulus control around sleep, values → one occupational action. I do not turn the OT note into a psychotherapy process note.

### How I make sense
1. What occupational problem exists?  
2. Person / environment / occupation — which barrier?  
3. What did we do today and how did they respond?  
4. What is the next OT step?

Problem statement shape: *Unable to [occupation] because [contributing factor], as observed/reported today.*

### How I write
Descriptions / Intervention → Progress Summary / Evaluation → Areas for Improvement → Follow Up Plan.  
Stay occupation-based. Home visits keep environment when it was there.

## Clinical psychologist

Holds **clinical process**: observation, formulation, named intervention, homework, risk, boundaries of opinion.

### When I know the diagnosis
I use it as the clinical question in the background — not as a line to re-stamp.

- I notice domains and differentials that showed up (including MSE-relevant observation: affect, speech, thought, SI) **only if I saw or was told them**
- Diagnostic consideration in the impression **only if it is already in the file or this contact named it**
- Scores stay as written — no severity band, no new Dx from a raw score
- I separate **Clt report** / **my observation** / **clinical opinion** / **test data**

### When I know the approach
That is the method of this session: a named skill (exposure step, defusion, scaling, OARS…), how they engaged, what is set for next time.

- I do not complete a hexaflex, a full 5P, or a thought-record template that we did not use
- Formulation language (TFB, values, exceptions, maintaining processes) only if we actually worked it
- Bare “CBT done” is not how I think or write

### How I make sense
- What do today’s symptoms/behaviour mean in this frame?  
- Functioning and risk (as elicited)  
- Progress toward therapy goals  
- What maintained the problem *today* (if evidenced)  
- Was the session aim met?

### How I write
Objective → Behavioral Observation → Description or Progress → Clinical Impression → Intervention → Plan and Follow-up.  
Impression synthesises; Intervention names the skill + response; Plan is homework and next focus **as agreed**.

## Same case, three brains (quick contrast)

Contact: low mood, not going out, practised a short walk, denies SI. File: Depression. Approach: CBT.

| SW | OT | CP |
|----|----|----|
| Mood/anhedonia in the week; walk as agreed task; any family/work/money around it; SI as disclosed; next: follow up walk + care-plan goal | Not going out = community / leisure / IADL participation; walk as graded occupational practice; next occupation-sized step | Mood as reported; walk as BA; thought work only if done; impression: withdrawal maintaining low mood *if that was the work*; homework as set |

Do not write the other two columns.

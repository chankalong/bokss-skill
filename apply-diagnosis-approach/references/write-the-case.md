# Write the case after you have thought

After Notice → Work → Make sense, write in the **role’s** structure. Do not add extra saved sections. Do not paste diagnosis or approach cards.

Facts come only from this contact (or the draft you are editing). Bundled references only supply language and what you knew to look for.

## Social worker / Case Worker

| Section | After thinking with diagnosis | After thinking with approach |
|---------|------------------------------|------------------------------|
| **Objective** | Session aim in case language (review mood/sleep; support after conflict) — not “complete MDD assessment” unless that was the aim | Name the planned method only if that *was* the aim |
| **Summary of Content** | Condition: domains and function that showed up. Topics, continuity, liaison | What you did (named skill) + Clt response. Quotes stay here |
| **Worker's Assessment** | Progress vs care-plan; synthesis of today’s domains. File Dx only if already in the record. Differentials preserved | Formulation (TFB, avoidance, exceptions, values) only if used today |
| **Plan or Action** | Next steps already agreed — not “care often linked” from the diagnosis | Homework / next skill only if set today |

Assessment synthesises. It does not repeat Summary.

## OT

| Section | After thinking with diagnosis | After thinking with approach |
|---------|------------------------------|------------------------------|
| **Descriptions / Intervention** | Occupation-linked function (sleep, meds, safety, meal prep) if assessed — not DSM criteria | Method only as used in activity |
| **Progress Summary / Evaluation** | Change in occupational performance | Response to today’s method, not modality theory |
| **Areas for Improvement** | Occupation deficit ↔ person/env/occupation factor from today | Not “missing CBT homework” unless OT set it |
| **Follow Up Plan** | Next occupation-sized step | Not a psychotherapy homework menu |

## CP

| Section | After thinking with diagnosis | After thinking with approach |
|---------|------------------------------|------------------------------|
| **Objective** | Clinical aim of this session | Planned method if that was the aim |
| **Behavioral Observation** | MSE-relevant items only if observed | Do not invent MSE because the diagnosis lists those domains |
| **Description or Progress** | Domain updates, life events, homework follow-through | What was practised, in narrative |
| **Clinical Impression** | Function, risk as elicited, diagnostic consideration only if already in file/contact, maintaining factors if seen | Approach formulation if used (beliefs tentative; values in Clt words) |
| **Intervention** | — | Modality + **named skills** + engagement. No “CBT done” |
| **Plan and Follow-up** | Safety / liaison only if in the contact | Homework and next focus only if agreed |

## The sentence that should be true

```
what I noticed today  +  work I actually did  +  how they responded
        →  my professional sense  →  a plan we agreed
```

Never:

```
full diagnosis card  +  textbook session recipe  →  a complete-looking note
```

## Risk

Risk that was in the contact stays in the narrative. Diagnosis knowledge (“diagnosis alone does not imply violence”) does not delete it. Approach knowledge does not move it into a miracle question or values exercise that did not happen.

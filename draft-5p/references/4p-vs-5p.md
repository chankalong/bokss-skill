# 4P vs 5P — which scaffold to use

## Definitions

**5P** = Presenting + Predisposing + Precipitating + Perpetuating + Protective.

**4P** (common variant) folds Presenting into the opening problem statement / first Assessment paragraph, then uses Predisposing, Precipitating, Perpetuating, Protective.

## Comparison

| | 5P | 4P |
|---|----|----|
| Explicit “why now” heading | Yes (Presenting) | Often merged into intro |
| History / vulnerability | Predisposing | Predisposing |
| Triggers | Precipitating | Precipitating |
| Maintaining factors | Perpetuating | Perpetuating |
| Strengths | Protective | Protective |
| Best when | Teaching consistency; AI rewrite clarity | Teams already omit Presenting heading |

## ICCMW pilot rule
When the user asks for formulation, structure Assessment as **5P** headings. If a human writer clearly used 4P, you may mirror their headings but still keep content fidelity.

# Rules when generating 5P from a draft

## Hard rules (non-negotiable)
1. Every bullet must be traceable to the draft / source notes  
2. Missing P → `[Insufficient information in draft: <P name>]`  
3. Never invent trauma, ACE scores, diagnosis, or risk to “complete” a nice 5P  
4. Label source: (Clt report) / (Wher observation) / (file)  
5. If approach is selected, you may organise maintaining processes using that lens **only when evidenced**  

## Soft guidance
- Prefer fewer accurate bullets over many speculative ones  
- Presenting should match Clt’s priority, not the worker’s favourite theory  
- Protective factors must be as concrete as problems  
- Use dates when the draft has them  

## Refusal / sparse-draft pattern
If the user asks for a “full formulation” from three lines:
- Return sparse 5P  
- Multiple insufficient-information markers  
- One line: more history/assessment required before a complete formulation

# Turning 5P into Plan

## Method
1. List **Perpetuating** factors as targets  
2. For each target, write one intervention that appears in the draft **or** is explicitly consistent with the selected approach — if unsure → `[Insufficient information: agreed intervention for …]`  
3. List **Protective** factors as resources to use  
4. Convert into goals + actions + owners + review date

## Quality checks
- Every major Perpetuating factor has a plan response **or** an explicit deferral  
- Protective factors are used, not only praised  
- Plan does not introduce new modalities absent from draft  
- Goals are observable enough to review  

## Anti-patterns
- Beautiful 5P with a vague Plan (“continue support”)  
- Plan full of new therapies not discussed  
- Formulation ignored when writing care plan

# Care stages — Exploration → Insight → Action

Use stages to choose note depth and which references to read. Stages describe **documentation purpose**, not a requirement that every client follows three formal phases.

| Stage | Purpose | Typical note kinds | Capture |
|-------|---------|--------------------------------|---------|
| **Exploration** | Trust, presenting problem, history/screens, MSE, risk as done | Intake; early assessment | Why here now; coverage of screens; safety; next step |
| **Insight** | Sense-making, goals, formulation, approach choice | Assessment; review; formulation section | 5P / working understanding; Clt goals; modality if used |
| **Action** | Agreed change work, care plan, progress on goals | Care plan; SW / OT / CP progress notes | Goals, interventions, Clt actions, review date |

## Stage lens (documentation depth)

| Question pattern | Prefer stage lens |
|------------------|-------------------|
| “What’s missing from intake?” | Exploration → intake process |
| “Do we have a formulation?” | Insight → formulation |
| “What’s the care plan / next goals?” | Action → [intervention-planning](references/intervention-planning.md) |
| “What changed since last month?” | Action + prior Action/Insight notes |

## Rules
- Do not invent that a stage was “completed”
- Progress notes can stay in Action while still updating Exploration facts (e.g. new risk disclosure)
- Risk can appear in any stage — preserve and flag; never invent

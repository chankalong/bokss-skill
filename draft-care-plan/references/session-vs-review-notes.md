# Session vs review vs assessment vs care plan

Choosing the right depth prevents the rewriter from turning a brief contact into a fake full history — or a period review into a single-session anecdote.

## Decision guide

| Note kind | Typical situation | Time span covered | Depth |
|-----------|-------------------|-------------------|-------|
| Intake | First contacts / opening | First meeting(s) | Presenting + screen + next step |
| Progress / session | Ordinary follow-up | This contact only | Aim → what happened → sense-making → plan |
| Assessment | Formal MH assessment | Cumulative info to date | Multi-domain + formulation |
| Review | Case review / conference / quarterly | Period since last review | Goal status, risk update, reformulation |
| Care plan | Goal/intervention document | Forward-looking plan | Goals, interventions, review date |

## What belongs in a progress / session note
- Purpose of **this** contact
- What was said/done **today**
- Short Assessment of today’s work
- Concrete next actions

**Usually does not belong:** full developmental history, complete med list rewrite, new 5P from scratch (unless the user asked for formulation and the draft supports it).

## What belongs in a review note
- Summary of period (contacts, major events, goal progress)
- What improved / stalled / worsened — with evidence from notes
- Updated risk picture **as currently documented**
- Updated 5P if formulation refresh is requested
- Decisions: continue / change goals / step up-down / discharge planning discussion

## What belongs in care plan
- Agreed goals (Clt-owned wording when available)
- Who delivers which intervention
- Clt/family actions
- Review date and success indicators
- Not a session narrative

## Rewrite errors to avoid
1. Inflating a 15-minute phone check into a full assessment
2. Writing “review” that only describes one session’s chat
3. Quietly changing care-plan goals inside a progress note without labelling them as goal changes
4. Copying old history blocks into every progress note

## Examples (synthetic)

**Progress:** “Objectives: review job homework. Summary: 2 applications sent; avoided phone interview. Assessment: avoidance maintains anxiety. Plan: one practice call; next Tue.”

**Review:** “Period 1 Jun–1 Jul: 4 sessions. Goal 1 (volunteer weekly): attended 2/4. Risk: no SI this period (last assessed 20 Jun). Perpetuating: unstructured mornings. Plan: revise goal to fortnightly volunteer + morning walk ×3.”

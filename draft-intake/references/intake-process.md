# Intake process — documentation guidance

**Care stage:** **Exploration** (see [care-stages](references/care-stages.md)) — trust, presenting problem, history/screens, risk as done, next step. Use when writing an intake / first-contact note.

ICCMW intake tools include copies of Morrison (*The First Interview*) **Summary of Initial Interview** (process map) and **Semistructured Interview** (diagnostic screens). Use them as **coverage checklists**. Do **not** paste copyrighted question banks into the note — rewrite only what the worker actually asked and recorded.

## Aims of intake documentation
1. Why the person is here now (chief complaint + free speech)  
2. Enough history of present illness + background to decide next steps  
3. Safety / risk as screened  
4. Engagement, role explanation, confidentiality limits, next appointment  

## Process map (from Summary of Initial Interview — adapted)

| Phase | Capture in notes when done |
|-------|----------------------------|
| **Openings** | Introduce role; time/goals of interview; help Clt feel comfortable |
| **Chief complaint** | Why seeking help — open but directed; Clt’s words |
| **Free speech** | Allow Clt to amplify; listen for cognitive problems, substance, psychosis, mood, anxiety/avoidance, physical complaints, social/personality issues; summarise before moving on |
| **History of present illness** | Symptom type, onset, severity, frequency, duration, context, stressors; vegetative (sleep, appetite/weight, diurnal variation); previous episodes & treatment (type, compliance, effects, hospitalisations); consequences (relationships, work, legal, interests) |
| **Feelings / coping** | How Clt copes; do not invent defence labels unless worker used them |
| **Personal & social history** | Childhood/education **only if elicited**; adult living situation, finances, homelessness history, supports, family, work, military/legal if asked; leisure; religion if disclosed; sexual history **only if asked and relevant** — careful lead-in for abuse |
| **Substance** | Types, years, quantity, consequences, loss of control, Rx misuse — past and current |
| **Suicide / self-harm** | Gradual entry OK; ideation, attempts, seriousness — **as asked** |
| **Personality / lifelong patterns** | Only if assessed (self-report, informants, observation) |
| **Family history** | Mental illness / suicide / substance in blood relatives — if asked |
| **Medical history** | Major illnesses, operations, non-psych meds, allergies, hospitalisations, impairments; ROS items relevant to MH if covered |
| **MSE** | See mse checklist — appearance through insight/judgement |
| **Closure** | Summarise; next appointment; “any questions?” |

## Semistructured screen **topics** (coverage only — not a script to invent)

When rewriting, mark screens as done / not done / insufficient. Positive screen → note that follow-ups were/were not completed.

| Screen cluster | Topic |
|----------------|-------|
| A | Depressed mood / anhedonia |
| B | Elevated / irritable / overactive periods |
| C | Panic / sudden anxiety or somatic panic symptoms |
| D | Specific phobia / agoraphobic situations |
| E | Obsessions / compulsions |
| F | Trauma re-experiencing / avoidance |
| G | Excessive worry |
| H / J | Hallucinations / paranoia / special mission / unexplained strange experiences |
| K | Alcohol / drugs / Rx misuse / others’ concern |
| L | Memory / amnestic periods |
| M | General health / medical attention |
| (later sections) | Background, personality, risk detail — no skip just because screens negative |

**Rule for AI rewrite:** Never invent “yes” to a screen. If draft is silent → `[Insufficient information: <screen topic>]` or omit.

## Typical ICCMW note blocks (rewrite target)

### A. Administrative / context
Date, worker, setting; referral source/reason; who attended; interpreter if any.

### B. Presenting concerns
Clt words; onset; why now; hopes from service.

### C. HPI & background (only if elicited)
Use domain tags `(Bio)` `(Psych)` `(Social)` `(Cultural)` when helpful.

### D. Risk & safeguarding
SI/self-harm/harm to others/child protection — only what was asked/answered; actions taken.

### E. MSE
Domains actually covered (mse checklist).

### F. Engagement & process
Rapport, confidentiality explanation, misconceptions corrected, resistance handled factually.

### G. Plan
Next step (MH assessment, OT, CP, joint); interim supports; referrals.

### H. Questions to resolve
Every skipped screen/domain that still matters.

## Rewrite dos and don’ts
| Do | Don’t |
|----|-------|
| Keep Clt wording for chief complaint | Copy Morrison question lists into the note |
| Mark unasked domains as insufficient | Invent childhood trauma / sexual history / Dx |
| Separate free speech themes from closed-screen findings | Diagnose beyond what is documented |
| Preserve risk wording | Soften or escalate risk |

# Mental State Examination — writing guidance

Aligned with the agency **Mental Status Examination Rapid Record Form** (Jeff Patrick, 2000; freely usable by MH practitioners). Use the form when available. This card organises free-text drafts into clear domains **without inventing unassessed findings**.

## Purpose in ICCMW notes
MSE is a **structured snapshot** of presentation at the time of contact. It supports risk thinking and handoff — it is **not** a diagnosis.

## Domains (from agency form — record only what was assessed)

### General description
| Domain | Tick / note examples from form |
|--------|--------------------------------|
| **Appearance** | Weight band; hair; wounds/scars/tattoos; grooming (disheveled, soiled, odour); dress (under/overdressed, bizarre) |
| **Behaviour** | Walk/gait; combativeness; repetition (gestures, twitches, stereotypy, echopraxia); overactivity / psychomotor agitation; catatonia signs if relevant |
| **Speech** | Rate, intelligibility, volume, quality (hesitant, monotonous, echolalia…), quantity (talkative → mutism) |
| **Attitude to examiner** | Cooperative, attentive, evasive, hostile, seductive, indifferent… |

### Mood and affect
| Domain | Note |
|--------|------|
| **Mood** (Clt report / labelled) | Euthymic, dysphoric, depressed, anxious, irritable, euphoric…; neuro-vegetative if asked (sleep, appetite, libido) |
| **Affect** (observed) | Normal / restricted / blunted / flat; appropriateness; lability |
| Separate **mood** (said) from **affect** (seen) |

### Perception
Hallucinations (auditory, visual, olfactory, gustatory, tactile, somatic…); dissociation (depersonalisation, derealisation) — **only if assessed**. Prefer “Not assessed” over invented “nil”.

### Thought
| Domain | Note |
|--------|------|
| **Content** | Preoccupations, obsessions/compulsions, delusions (type if present), phobias |
| **Risk content** | Suicidal ideation (history, current, plan, means, impulsiveness, settling affairs); hostile/violent intent (history, current, plan, means) — as on form **Risk Assessment** |
| **Form** | Circumstantial, tangential, flight of ideas, loosening, blocking, poverty of speech/content… |

### Cognition & capacity
Orientation (person/place/time); attention/concentration; memory (immediate / short / long); language screens if done; abstract thinking if done; **insight**; **judgement**.

### Current treatment (if on form)
Current psychotherapy / psychoactive medication **as documented**.

## Critical writing rules
1. Prefer **“Not assessed in this contact”** over fabricated “NAD / nil”  
2. Separate Clt-reported mood from observed affect  
3. Risk findings → also Plan / Risk-management flags if actions taken  
4. MSE is time-stamped; do not merge last month’s MSE into today’s without saying so  
5. Do not dump every form tick into a progress note — summarise what matters  

## How to place MSE in note formats
- **CW progress:** short bullets in Summary when relevant  
- **SOAP:** under **O**bjective  
- **DARP:** under **D**ata  
- **Assessment:** dedicated MSE subsection  

## Synthetic example (partial)
Appearance tidy; behaviour cooperative; speech normal rate; mood “anxious”; affect tense; thought content: worry about MTR panic, no SI elicited; perception not assessed; oriented ×3; insight fair regarding avoidance.

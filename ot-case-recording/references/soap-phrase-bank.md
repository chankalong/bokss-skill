# SOAP-style phrase stems (style only)

Use these as **wording patterns** when polishing draft facts into the four headings.  
**Never** copy a stem that adds facts, prompts, times, referrals, or outcomes not in the draft.

Map to the four headings:
- **S** / report stems → Descriptions / Intervention (Clt report)
- **O** / observation stems → Descriptions / Intervention (performance)
- **A** / interpretation stems → Progress Summary / Evaluation (+ Areas when deficit remains)
- **P** / plan stems → Follow Up Plan

Prefer **past tense** for completed visits.

## S — Subjective / Clt report (starters)

- Client felt less anxious…
- Client expressed a desire to improve…
- Client reported concerns about…
- Client stated that maintaining a structured daily routine has…
- Client agreed / disagreed that…
- Client admitted that…
- Client rejected…
- Client satisfied…
- Client acknowledged the impact of mental health symptoms on…

## O — Objective / observed performance (patterns)

- Maintained / sustained attention to a … task for approximately __ minutes with __ verbal prompt(s)…
- Initiated conversation with __ peers during break time and maintained reciprocal interaction for approximately __ minutes…
- Completed a … task involving … within __ minutes. Required __ reminder(s) regarding task sequence…
- Maintained appropriate eye contact…
- Independently identified the correct bus route and fare… using a transport map…
- Followed group rules appropriately…
- Able to follow a basic cooking activity with … assistance…
- Demonstrated use of … skills as instructed…

## A — Assessment / evaluation (patterns)

Progress:
- Client demonstrated improvement in…
- Client showed increased ability to…
- Client continues to make gradual progress in…
- Client demonstrated increased willingness to…
- Consistent attendance and active participation indicate good engagement…

Functional impact:
- This may affect the client’s ability to…
- These difficulties continue to impact occupational performance in…
- Current symptoms interfere with participation in…
- Reduced concentration continues to affect task completion efficiency and may limit vocational performance…
- Difficulties with task organisation and prioritisation continue to interfere with efficient task performance…

Recovery focus:
- Findings indicate increased readiness for…
- Progress observed supports movement towards recovery goals…
- Increased participation in community-based activities suggests progress towards recovery goals related to social inclusion…
- Continued intervention is recommended to further develop…
- Client demonstrated partial insight into the impact of mental health symptoms on daily functioning…

## P — Plan stems (only if draft supports)

- Continue weekly … to…
- Continue OT intervention focusing on… / Continue training on… / Continue psychoeducation on…
- Progress to… / Introduce… / Monitor… / Review… / Encourage… / Facilitate…
- Liaise with… / Collaborate with the vocational rehabilitation team regarding…
- Evaluate readiness for… / Reassess … in __ weeks…
- Refer to SET / IVRSC / Counselling / family therapy / CP / HWH — **only if named in draft**
- Encourage continued attendance at Day training and other ICCMW activities — **only if in draft**

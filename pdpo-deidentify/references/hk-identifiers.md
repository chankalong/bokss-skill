# Hong Kong identifier scan list

Load when the draft is long, mixed Chinese/English, or a screenshot/OCR dump.

## Direct identifiers

- Full name, 別名, maiden name, child’s name in a carer note
- HKID / passport / birth cert numbers
- Phone, fax, WhatsApp, WeChat, Signal
- Email, social handles, video-call IDs
- Full address, room/flat/block, named estate, hostel bed number
- Exact DOB; exact age + named school + form/class
- case-file / ICCMW / halfway-house / SWD / HA / CSSA / sick-leave file numbers
- Bank account, FPS, Octopus if uniquely tied to a person
- Named school, employer, church, shop the person is known at
- Named private doctor / specific OPD clinic when the combination is rare
- Photos, voice notes, scanned letters with letterhead — describe, do not copy letterhead text into the model if avoidable

## Quasi-identifiers (flag, then decide with the worker)

- District + rare diagnosis (e.g. named village + uncommon presentation)
- Exact occupation in a small trade + age + gender
- Sibling count + school name + form
- Unique physical description
- Quoted speech that names a third party who is identifiable in a small estate

Keep the clinical fact; drop or generalise the locating detail if the worker agrees (“a public estate in Kwai Tsing” vs block+flat).

## Do not treat as identifiers

- Generic “HA psychiatrist”, “地區醫院”, “中學”, “家人”
- Symptom language, scale **names** without a unique hospital number
- BOKSS service names (樂心匯、ICCMW) as the provider — those are the agency, not the client

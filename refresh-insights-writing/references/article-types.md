# Insights article types (distilled)

Use these labels when matching a brief to a skeleton. Patterns, not full articles.

| Type | Signal | Typical length | Must-have slots |
|------|--------|----------------|-----------------|
| 標準熱話科普 | `【…】` or plain pain-point title; tags `#文章` | ~1500–2800 | Hook → 2–4 mechanisms → 2–4 steps → soft CTA |
| Re:Fresh Plus 深度專欄 | Title prefix `【Re:Fresh Plus專屬內容】深度專欄 \|` ; tag `#深度長文` | ~2800–4500 | Phenom + named construct + personal/team/org layers of practice |
| 日子／國際日專題 | Calendar hook in title (`【9.10…】`) | 標準–深度 | Extra **Safety line** + FAQ / 守護行動 if suicide/trauma |
| 工作坊引流短篇 | Ends with workshop replay / signup CTA early | ~600–1200 | Hook + one mechanism tease + workshop CTA (full steps optional) |
| EAP 企業訪談 | `【Re:Fresh EAP系列・…篇】` ; often `#影片` | 視乎片長文字稿 | Employer pain → EAP measures → human quote; soft B2B CTA |
| 調查＋個案＋專家 | Agency survey numbers + 1 vignette + expert voice | 深度 | Cite survey N/% honestly; no reader diagnosis |

## Format habits to mirror

- Tags: always include `#文章` or `#影片`; theme tags 4–7
- Optional **AI 摘要** bullets on longer pieces (site may auto-show) — drafts can supply 2–4 bullets as 文章摘要
- Byline variants: `撰文：Name@Re:Fresh` / `撰文︱Name（組織心理學家）` / `作者：Name（本處輔導員）`
- Spoken Cantonese only inside「」; body stays 書面語

# Re:Fresh style patterns (load when drafting)

## Opening moves

- Scene + question: 「最近，你是否感受到一種難以言喻的疲憊？」
- Trending frame: 「最近，『X』成為各大社交平台的熱話……其實，這背後並非魔咒，而是……」
- Quoted lived speech (Cantonese OK inside quotes): 「放假仲攰過返工……」
- News with care: state facts briefly → 「關注事件之餘，也請別忘了照顧自己。」

## Section heading patterns

- `奪回內在控制權：…`
- `明明是…，為什麼我們也感到「受傷」？`
- `如何守護…，而不被無力感吞噬？`
- `傾聽身體與情緒的「求救訊號」`
- `從「以A為中心」走向「B」`

## Practice block patterns

- 3 個小步驟 / 即時「心靈急救貼士」
- Structured scripts readers can copy (向上管理提問、親子一句話)
- Breathing: short, concrete counts (e.g. 4-4-4-4)—not a full therapy protocol
- Boundary scripts: turn vague demands into conditions

## Soft CTA patterns

- Workshop: 「想突破…？立即了解《…》工作坊」+ link placeholder
- Care: 「若情緒持續影響生活，請及早尋求心理輔導」
- EAP / Plus: only if brief asks for workplace column framing
- Workshop replay / signup mid or early for 引流短篇
- Safety FAQ block for suicide/trauma days (辨識 → 開解 → 專業協助／自我照顧)

## Title moves seen this week

- `痛點場景，拆解…，N 招…` (手足舊帳)
- `【Re:Fresh Plus專屬內容】深度專欄 | 數據／痛點 + 三招…`
- `【正向心理學】概念？從心理學一手掌握…` (construct bracket)
- Calendar: `【9.10世界防止自殺日】迷思？`

## New section habits

- Numbered conflict taxonomy (`常見的三種「舊帳」` + 一／二／三 with quoted Cantonese labels)
- Plus columns: **個人／團隊／企業** (or 個人／企業) practice layers
- Optional on-site **AI 摘要** → mirror as 文章摘要 bullets in drafts
- Explicit 「非精神疾病診斷」disclaimer when popular syndrome labels appear (Impostor etc.)

## Lexicon quick map (prefer → avoid)

| Prefer (HK) | Avoid |
|-------------|--------|
| 抑鬱、焦慮、精神健康 | 抑郁、焦虑症口吻堆砌、衛教 |
| 中學、小學、放榜、DSE | 國中、高中阶段 |
| 打工仔、上司、老細（quoted）、夾心階層 | 打工人 as default voice |
| 輔導、註冊社工、僱員支援 | 過早「臨床診斷」 |
| Body: 的／了／不是／在 | Body default: 嘅／咗／唔係／喺 |

**Register example**

- Title OK: `【DSE放榜日】放榜日點算好？…`
- Quote OK: 「放假仲攰過返工，日日喺屋企對住啲細路…」
- Body prefer: `每逢暑假，作為家長的你，是否也有這些矛盾和煩惱？`
- Body avoid: `好多家長係暑假都覺得頂唔順，成日喺度嘈…` (unless inside quotes)

**Register reminder**

Spoken Cantonese in「」for lived voice (`次次都係我做曬！`); surrounding narration 書面語.

## Source honesty

Good: 「意義治療法（Logotherapy）創始人 Viktor Frankl……」
Good: 「美國心理學家 Christina Maslach 將工作倦怠概括為三個面向……」
Bad: invented Mindlab / Sussex-style stats you cannot verify
Bad: APA reference list with placeholder author names

When the user needs citations and you lack them: keep mechanisms conceptual + add `參考資料：待補` with the claims that need sources.

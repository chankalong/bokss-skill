# Social Impact Measurement

Impact is not a single result. It is linked change across multiple dimensions, connecting and spreading among different objects, and thereby creating greater value.

Use the attached eight-dimension framework as the primary coding and design lens. Keep measurement proportionate to the decision, intervention maturity, stakeholder burden, risk, budget, and available evidence.

## Core workflow

1. **Inspect the source.** Extract the intervention or 方法介入, requested fields/limits, target groups, existing KPIs, constraints, and unresolved claims.
2. **Map 影響的關係地圖.** Name the intervention at the centre. Identify objects. Scan all eight 影響方向. Keep only material cells. Trace 連結與擴散 across objects.
3. **Read the dimension reference before coding.** Use [eight change dimensions](references/eight-change-dimensions.md) for verbatim subtypes, bipolar directions, and measurement cues. Do not invent extra dimensions or rename the eight.
4. **Verify evidence claims.** Follow [framework and evidence safeguards](references/framework-and-evidence-safeguards.md) before claiming attribution, endorsement, prevention, cost saving, or statistical significance.
5. **Apply complementary frameworks where they fit.** Read [IMP 五大維度, SROI, and NCSS SEF](references/imp-sroi-ncss-sef.md) when the user or funder names them, when standardised SSA metrics are needed, or when valuation is requested. Do not list acronyms in a short field unless asked.
6. **Build the measurement architecture.** For each material cell, define indicator, data source, timing, comparison, owner, use of findings, and limitation. Distinguish outputs, outcomes, contribution, and (only if justified) economic valuation.
7. **Draft the requested deliverable.** Retain source structure and language unless a redesign is requested. For constrained grant fields, use [the point-form template](templates/impact-grant-point-form-template.md).
8. **Validate before delivery.** Confirm the map, selected dimensions, IMP/SROI/SEF use, evidence language, ethics, limits, and change record.

## 影響的關係地圖

Build research or programme contribution from **影響方向 × 對象**.

Centre the work as **研究（方法介入）** or the actual programme. The intervention produces linked effects in:

| Node | Role in the map |
|---|---|
| 影響方向（8大面向） | Which kinds of change occur |
| 變化 | That change is multi-faceted, not a single KPI |
| 關係 | Connections among people and organisations |
| 時間 | When change starts, how long it lasts, how fast it spreads |
| 價值 | Meaning, worth, and visibility created |

Default objects:

| 對象 | Use for | Analogous object if the context is not education/research |
|---|---|---|
| 學習者 | Participants, students, residents, clients | Primary beneficiaries |
| 教學者 | Teachers, facilitators, practitioners, staff | Delivery agents |
| 產業 | Employers, markets, professional fields | Industry / economy |
| 社區 | Place, community, civic groups | Community / place |
| 學術理論 | Knowledge, methods, policy, field discourse | Knowledge / policy / field |

Do not drop an object silently. If it is not material, say so in one clause.

|---|---|---|---|---|---|---|---|---|
| 學習者 | | | | | | | | |

| 產業 | | | | | | | | |

Leave cells empty rather than forcing a story. A credible map has a few well-evidenced cells plus explicit links among them.

After filling cells, write the **diffusion path**: which object changes first, what that enables in other objects, and what value that linkage creates.

## Select dimensions; do not measure everything

The eight directions, in order:

1. **量的變化** — 數量、規模、程度上的改變
2. **質的變化** — 品質、狀態、清晰度上的改變
3. **結構性變化** — 系統、流程、組織結構上的改變
4. **關係性變化** — 人與人、組織與組織之間的關係改變
5. **心理與態度變化** — 內在心理狀態與態度的改變
6. **時間性變化** — 發生時機、持續時間、擴散速度的改變
7. **能力與行為變化** — 能力的習得與行為的改變
8. **價值與意義變化** — 價值創造、意義建構與再定義

Rules:

- Quantity is never the whole impact. If only 量的變化 is claimed, look for missing 質、能力與行為、關係, or 價值與意義.
- Record bipolar directions (變好/變差, 變快/變慢, 增加自主/降低依賴). Intended gains and unintended losses both belong on the map.
- Prefer stakeholder language for the outcome, then classify it into a dimension. Do not reverse this: do not start from a dimension name and invent an outcome.
- Name connections. Example: 習得新技能 (學習者) → 行為改變 in 創作流程 (教學者/產業) → 可見化 of 地方故事 (社區).

## Measurement architecture

Use this matrix for every material cell:

| 對象 | 影響方向 / subtype | Observed or intended change | Indicator and data source | Timing and comparison | Owner and use | Limitation / rival explanation |
|---|---|---|---|---|---|---|

### Choose measures to match the dimension

- **量:** counts, rates, thresholds, reach, cost, time. Define the unit of count and avoid mistaking volume for benefit.
- **質:** quality, accuracy, stability, simplicity, clarity. Use rubrics, observation, error/rework, or stakeholder judgement of the same construct over time.
- **結構:** process maps, role changes, tool replacement, integration or differentiation evidence. Before/after artefacts beat slogans.
- **關係:** network ties, distance between groups, power/decision rights, autonomy vs dependency. Include who gained or lost voice.
- **心理與態度:** motivation, self-efficacy, anxiety/resistance, beliefs, belonging. Use appropriate instruments; do not treat a mood item as a diagnostic claim.
- **時間:** retention/duration, diffusion/adoption speed, earlier onset, delay or prevention. Prevention claims need a counterfactual or strong contribution story.
- **能力與行為:** skill acquisition, habit/process change, transfer across contexts, internalisation from 被動操作 to 主動策略. Look for use beyond the original task.
- **價值與意義:** value-add, role redefinition, 活化/再生 of resources or culture, 可見化 of tacit knowledge or place stories. Qualitative and artefact evidence are usually required.

Capture reach, dose, completion, retention, and implementation fidelity alongside outcomes. Define baseline and follow-up before collection. Disaggregate by equity variables only where consent, privacy, sample size, and interpretability allow.

Separate these layers:

| Layer | Definition |
|---|---|
| Inputs | Resources invested |
| Activities | Work delivered |
| Outputs | Direct deliverables and reach |
| Outcomes | Changes in the eight dimensions, experienced by objects |
| Impact / contribution | Longer-term change to which the intervention plausibly contributes, including 連結與擴散 across objects |

## IMP 五大維度, SROI, and NCSS SEF

The eight dimensions classify the kind of change. These three lenses are complementary, not substitutes. Full procedures: [IMP 五大維度, SROI, and NCSS SEF](references/imp-sroi-ncss-sef.md).

| Lens | Use when | Minimum substance |
|---|---|---|
| **IMP 五大維度** | Default stress-test on every material cell | What (outcome and importance); Who (including underserved); How Much (規模、深度、持續); Contribution (vs what would have happened anyway); Risk (likelihood × severity) |
| **NCSS SEF** | Singapore SSA / funder context and a matching programme group | The current NCSS sector-outcome metric for that group, plus WHOQOL-BREF (18+) or KIDSCREEN-27 (<18) as the QOL monitor. Confirm the live table before naming a tool. |
| **SROI** | Decision needs valuation and outcomes are already evidenced | Stakeholder-informed proxies; deadweight, attribution, displacement, drop-off; sensitivity; no promised ratio |

Do not import SEF tools (ZBI, ACT SG, C-SSRS, and similar) onto unmatched education, design, or 地方創生 work. Do not monetise a cell that lacks outcome evidence.

## Ethics, inclusion, and data governance

Apply to every design; elevate for children, vulnerable people, health, protection, migration, finances, or other sensitive contexts.

- Minimise data collection and state a legitimate use for every field.
- Define consent, withdrawal, confidentiality, access, retention, and aggregation before collection.
- Build safeguarding and referral routes where questions could identify risk.
- Involve affected objects in defining what meaningful change looks like, especially for 關係性變化 and 價值與意義變化.
- Do not claim attribution, prevention, cost savings, or statistically significant change unless design and data support them.

## Grant and impact writing

Preserve numbering, headings, point-form style, terminology, and field limits. Prefer one operational statement over a list of dimension names.

In a short “objectives” field, cover only what the limit permits:

1. object and need/barrier;
2. intervention pathway;
3. near-term change in one or two material dimensions, plus how it will be monitored;
4. longer-term contribution via 連結與擴散;
5. one safeguard or limitation.

When the user asks what changed, deliver:

1. **Paste-ready revision** with only new or materially strengthened text marked, e.g. `[新增：目的]`.
2. **Additions register:** inserted text, framework basis, why it is new, operational implication.

| Classification | Meaning |
|---|---|
| Retained | Original idea or wording remains substantively unchanged |
| Light edit | Clarity or fit-to-limit; no new commitment |
| New design element | New outcome, measure, safeguard, loop, partnership, or delivery commitment |
| New evidence framing | Existing service linked to a verified framework without a new operational commitment |

## Quality gate

- [ ] 影響方向 × 對象 matrix is filled only where material; empty cells are intentional.
- [ ] Dimension names and subtypes match [eight change dimensions](references/eight-change-dimensions.md); bipolar unintended change is considered.
- [ ] A diffusion path across objects is stated, or its absence is explained.
- [ ] Outputs, outcomes, contribution, attribution, and economic valuation are not conflated.
- [ ] Indicators match the dimension (counts are not used as the sole proof of 質、關係、意義, or 內化).
- [ ] Framework, endorsement, and causal claims have current primary-source support or are qualified.
- [ ] IMP 五大維度 are applied to material cells, or their omission is explained; Contribution is not confused with How Much depth.
- [ ] NCSS SEF metrics, if used, match the live programme-group table; licences, training, and safeguarding are named for clinical/psychometric tools.
- [ ] SROI, if used, includes adjustments, proxy sources, and sensitivity; the ratio is not presented as a guarantee.
- [ ] Privacy, consent, safeguarding, equity, and burden are addressed at the required level.
- [ ] Field limits, numbering, and language are preserved where requested; new content is distinct from retained text.

## Delivery

Deliver in the user’s language. Keep framework terms in Traditional Chinese as written on the source slides. Unless inline-only output is requested, provide the contribution matrix plus the requested narrative, measurement table, and change record.

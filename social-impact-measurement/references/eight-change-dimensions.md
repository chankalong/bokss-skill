# Eight change dimensions

Use these terms verbatim. Do not add a ninth dimension or merge two dimensions into one label. Classify an observed change into the best-fit subtype, then choose measures. Record both poles when evidence supports them.

## 1 量的變化

數量、規模、程度上的改變

| Subtype | Meaning |
|---|---|
| 變快 / 變慢 | 效率、反應時間、學習速度 |
| 變多 / 變少 | 產出量、錯誤率、成本、時間投入 |
| 變廣 / 變窄 | 應用範圍、受眾、涵蓋領域 |
| 變深 / 變淺 | 理解深度、投入程度 |
| 變大 / 變小 | 規模、影響範圍 |
| 變高 / 變低 | 滿意度、意願、門檻 |

Common positive poles: 效率提升（變快）、產出增加（變多）、影響擴大（變大）、門檻降低（變低）.

**Measure with:** time, counts, rates, coverage, cost, threshold/access metrics. State the unit of count. A faster or larger output is not automatically a better outcome.

## 2 質的變化

品質、狀態、清晰度上的改變

| Subtype | Meaning |
|---|---|
| 變好 / 變差 | 品質、精確度、可靠度 |
| 變穩定 / 變波動 | 一致性、可靠性 |
| 變簡單 / 變複雜 | 操作流程、認知負荷 |
| 變清晰 / 變模糊 | 概念理解、目標感 |

Common positive poles: 品質提升（變好）、更清晰（變清晰）、更穩定（變穩定）、更簡單（變簡單）.

**Measure with:** quality rubrics, error/rework, inter-rater or test-retest consistency, task-load or usability evidence, and whether goals/concepts are stated more clearly by the same stakeholders over time. Simpler is not always better; note if 變複雜 is an intended specialisation.

## 3 結構性變化

系統、流程、組織結構上的改變

| Subtype | Meaning |
|---|---|
| 轉移 | 重心轉移（如：從技術操作轉向創意構思） |
| 重組 | 流程、角色、分工的改變 |
| 取代 | 舊工具、舊方法被替換 |
| 整合 | 原本分散的東西被串接起來 |
| 分化 | 原本單一的東西產生多樣性 |

Diagram poles: 轉移／重心轉移；重組／流程與角色；取代／替換原有；整合／串接整合；分化／多樣發展.

**Measure with:** before/after process or org maps, role descriptions, tool logs, evidence that previously separate parts now connect, or that a single track has branched. Do not code a training session as 結構性變化 unless roles, tools, or workflows actually changed.

## 4 關係性變化

人與人、組織與組織之間的關係改變

| Subtype | Meaning |
|---|---|
| 縮短距離 | 師生、產學、城鄉之間 |
| 增加連結 | 跨領域合作、社群形成 |
| 改變權力關係 | 去中心化、賦權 empowerment |
| 降低依賴 / 增加自主 | 自主學習能力 |

Diagram poles: 縮短距離；增加連結；賦權賦能（去中心化）；增加自主.

**Measure with:** who talks to whom, new cross-group ties, decision rights, dependency on a central actor, and whether learners/partners can act without the original facilitator. Count of events is 量; a new tie or power shift is 關係.

## 5 心理與態度變化

內在心理狀態與態度的改變

| Subtype | Meaning |
|---|---|
| 提升動機、自信、自我效能 | self-efficacy |
| 降低焦慮、抗拒感 | — |
| 改變認知或信念 | 對 AI 的態度轉變 |
| 提升認同感、歸屬感 | 地方創生常用 |

Diagram poles: 提升動機與自信；改變認知與信念；提升認同感與歸屬感；降低焦慮與抗拒.

**Measure with:** repeated self-efficacy, anxiety/resistance, belief, or belonging items appropriate to the population; plus qualitative accounts. Do not infer diagnosis. Attitude toward a tool (e.g. AI) is this dimension, not 能力與行為, unless use actually changed.

## 6 時間性變化

發生時機、持續時間、擴散速度的改變

| Subtype | Meaning |
|---|---|
| 延續 / 持續 | 效果是否持久、留存率 |
| 加速擴散 | 採用曲線、普及速度 |
| 提早發生 | 創意產出提前出現 |
| 延後或預防 | 問題延後發生、風險預防 |

Diagram poles: 延續／持續（更持久）；加速擴散（更快速）；提早發生（更早出現）；延後或預防（降低風險）.

**Measure with:** follow-up retention, time-to-event, adoption curves, and (for 預防) a credible baseline or comparison. “We hope it lasts” is not 延續. Prevention is a high-burden claim; see safeguards.

## 7 能力與行為變化

能力的習得與行為的改變

| Subtype | Meaning |
|---|---|
| 習得新技能 | skill acquisition |
| 行為改變 | 使用習慣，創作流程 |
| 遷移 | 學到的能力能否應用到其他情境 (transfer) |
| 內化 | 從被動操作到主動策略 |

Diagram poles: 習得新技能；行為改變；內化策略（主動應用）；遷移應用（跨情境）.

**Measure with:** demonstrated skill, observed or logged habit/process change, use in a new context, and whether the person initiates strategy rather than following prompts. Course completion is an output. 內化 and 遷移 need evidence beyond the original workshop.

## 8 價值與意義變化

價值創造、意義建構與再定義

| Subtype | Meaning |
|---|---|
| 增值 | 作品、地方、品牌價值提升 |
| 再定義 | 重新定義設計師角色、教師角色 |
| 活化 / 再生 | 回收資源、文化資產（地方創生核心） |
| 可見化 | 隱性知識、地方故事被看見 |

Diagram poles: 增值提升價值；再定義角色與意義；活化再生資源與文化；可見化呈現（被看見）.

**Measure with:** valued artefacts or places, role narratives that have actually shifted in practice, reuse/regeneration of resources or cultural assets, and public or institutional visibility of previously tacit knowledge. Do not treat a press mention as 增值 unless worth to the object is evidenced.

## Coding rules

1. One change can touch two dimensions. Keep a primary code and a linked code. Example: faster production is 量／變快; cleaner work is 質／變好.
2. If the user only reports counts, ask what 質、能力、關係, or 意義 changed — or record that those cells are unknown.
3. Use the slide examples as analogies, not as required topics. 地方創生, AI, 師生, and 設計師/教師 are illustrations.
4. Negative or missing change is in-scope: 變差, 變波動, 變複雜, 變模糊, longer distance, higher dependency, rising anxiety, drop-off, failed transfer.
